# مقياس المازوخية الرقمي 3000 🔥💀
### The Ultimate Masochism Meter

اختبار ويب فكاهي وعصري يقيس مدى تحملك وتلذذك بالغباء والاستفزاز والمواقف اليومية المزعجة!

## 🌟 المميزات:
- تصميم عصري وأنيق (Modern Dark Mode & Glassmorphism)
- متجاوب مع جميع أحجام الشاشات (الجوال والكمبيوتر)
- مؤثرات صوتية داخلية بواسطة Web Audio API بدون أي ملفات خارجية
- عداد حي ومباشر لمستوى الألم والمازوخية
- شهادة إثبات مازوخية وتشخيص ساخر مع احتفال Confetti
- إمكانية نسخ ومشاركة النتيجة

## 🚀 التشغيل المباشر:
يمكنك فتح `index.html` في أي متصفح مباشرة، أو تجربة الموقع عبر GitHub Pages.
